# abx-artist-kit

unofficial tools for artists launching on [abx](https://docs.abx.io), art blocks' open protocol.
made by keyrun while shipping "nothing here moves" on base. not an art blocks project.
works on every chain abx ships: base, ethereum, arbitrum, robinhood and their testnets (checked on abx 0.6.0).

- [`proof/`](proof) .. rebuild an abx token from the chain alone (code + mint seed via eth_call, no servers)
- [`mcp/`](mcp) .. MCP server: rebuild, inspect, lint, render check, preflight, launch lessons, plus launch tools from a real drop: deploy cost per chain, edition preview, mint check, collectors, wave status, print export, marketplace check (read-only)

# abx-artist-kit

unofficial tools for artists launching on [abx](https://docs.abx.io), art blocks' open protocol.
made by keyrun while shipping "nothing here moves" on base. not an art blocks project.

- `mcp/` .. coming: preflight checks and launch gotchas for agents
